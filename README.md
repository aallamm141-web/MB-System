# MB Store — برنامج ويندوز

نفس واجهة السيستم الحالية، بس بتشتغل كبرنامج مستقل (من غير Chrome) على جهاز واحد.

## التثبيت (من غير Node ولا أدوات)
1. **فك ضغط الملف كامل** في فولدر (مش من جوه الـ zip).
2. دوس مرتين على **install.bat** (محتاج إنترنت، بينزّل حوالي 120 MB من GitHub ويتأكد إن الملف سليم).
3. هتلاقي اختصار **MB Store** على سطح المكتب. التثبيت لمستخدمك بس، ومش محتاج صلاحيات أدمن.
- لو ظهر تحذير SmartScreen: More info ← Run anyway (البرنامج مش موقّع رقميًا).
- لو التحميل فشل أو قطع: شغّل install.bat تاني.
- للإزالة: **uninstall.bat** (بيشيل البرنامج بس، والبيانات والنسخ بتفضل).
- لتحديث البرنامج بنسخة جديدة: فك الملف الجديد وشغّل install.bat تاني (البيانات مش بتتأثر).

## لو هتبني بنفسك
1. نزّل Node.js 22 LTS من nodejs.org.
2. افتح PowerShell جوه الفولدر:
   - `npm install`
   - `npm start`            ← تجربة البرنامج
   - `npm run test:e2e`     ← اختبارات شاملة على البرنامج الحقيقي
   - `npm run dist`         ← بيطلّع `dist\MB-Store-Setup-1.0.0.exe`
3. (اختياري) رفع الفولدر على GitHub وتشغيل Workflow "Build Windows installer" بيبني الـ EXE في السحابة.

## فين البيانات؟  (مهم)
- **البيانات:** `%APPDATA%\MB Store`  (جوه تخزين البرنامج). **ماتغيّرش اسم الفولدر ده ولا اسم "MB Store" في الكود** — البيانات مربوطة بيه.
- **النسخ الاحتياطي:** `Documents\MB Store Backups`  (ملف لكل يوم، آخر 30 يوم) — تقدر تغيّر المكان من الإعدادات.
- لو حذفت البرنامج (Uninstall) البيانات والنسخ **بتفضل**.

## نقل بياناتك من النسخة اللي على المتصفح
1. في النسخة القديمة: الإعدادات ← 💾 تنزيل نسخة الآن. احتفظ بالملف في مكان آمن.
2. في برنامج ويندوز: الإعدادات ← "استرجاع من ملف تاني…" واختار الملف.
3. راجع الأرقام (عدد الفواتير، المنتجات، رصيد الآجل، قيمة المخزون) قبل ما تبدأ شغل. سيب النسخة القديمة زي ما هي لحد ما تتأكد.

## الطباعة
الإعدادات ← 🖨️ الطابعة: اختار طابعة الفواتير ومقاس الورق، واضغط "طباعة تجريبية". بعدها الفاتورة بتتطبع من غير نافذة.

## ملاحظات
- البرنامج بيشتغل نسخة واحدة بس (لو فتحته تاني بيرجّعك للنافذة المفتوحة).
- بيحفظ نسخة أخيرة تلقائيًا لما تقفله.
- مفيش تحديث تلقائي في الإصدار ده: هتبعت ملف التثبيت الجديد وتثبّته فوق القديم (البيانات بتفضل).
